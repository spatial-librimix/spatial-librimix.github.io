# Spatial Librimix Companion page

Welcome to the Spatial Librimix companion page.
Spatial LibriMix (SLM) is a spatial (first-order ambisonic), reverberant extension of
[LibriMix](https://github.com/JorisCos/LibriMix) for multichannel speech
separation, extraction, and localization research.

Design choices are highlighted in our paper submitted to ICASSP27.
Technical details for the dataset and the ambisonic Image Source Model are [provided here](https://github.com/spatial-librimix/spatial-librimix.github.io/blob/main/Spatial_Librimix___Technical_Report-1.pdf).
Code and generation scripts are [provided here](https://github.com/liam-kelley/spatial-librimix).
SRIRs download is soon to be available on Zenodo.
Full dataset download is soon to be available on Hugging Face.
